Walkman Bridge — before you install

WHAT THIS IS
    A local app for putting music on a Sony NW-S705F Walkman (2007) without
    SonicStage. Drop in audio files of any common format; they are converted
    and written to the player's database so it can actually play them.

WHAT IT INSTALLS
    Everything it needs, in one folder under your user account:
    no administrator rights, nothing added to PATH, no system settings changed.
    It includes its own Java runtime and ffmpeg, so no prerequisites.

IT RUNS ENTIRELY ON YOUR COMPUTER
    The dashboard is served from your own machine (127.0.0.1) and is not
    reachable from the network. No accounts, no telemetry, no uploads.

IMPORTANT — BEFORE YOUR FIRST TRANSFER
    The Walkman's database format was reverse-engineered by the community, and
    this player family has a mixed history with the JSymphonic engine used here.

    Back up your player first: plug it in and copy the whole drive (including
    the OMGAUDIO folder) to a folder on your PC. That copy restores it.

    Also note: once Walkman Bridge writes to the player, Sony's SonicStage can
    no longer manage it without wiping the device first.

WINDOWS SMARTSCREEN
    This installer is not code-signed, so Windows may warn about an unknown
    publisher. Choose "More info" and then "Run anyway" to continue.
